* **Required OAuth Scopes:**
  * `https://www.googleapis.com/auth/spreadsheets` (Read/Write access to user's Google Sheets)
  * `https://www.googleapis.com/auth/drive.file` (Permission to discover and create specific app-managed files)
  * `openid`, `email`, `profile` (Basic user context identification)

### 1.2 Automated Synchronization Workflow
When a user logs in via the Google OAuth callback handler, the backend system initiates the following verification pipeline:

1. **File Search:** Scan the authenticated user's Google Drive storage root to locate an existing spreadsheet exactly matching the identity string template: `Solar ERP - {Company Name}`.
2. **Dynamic Generation:** If no file matches the query, initialize a new Google Spreadsheet object via a `POST` request to the Drive v3 creation endpoint.
3. **Internal Schema Provisioning:** Run a batch worksheet update sequence to establish the ten internal tabular sheets, defining explicit primary column strings in Row 1 for each tab.
4. **Token Storage Matrix:** Encrypt the retrieved OAuth `access_token` and long-lived `refresh_token` payloads. Store them within a secure, signed HTTP-only cookie JWT configuration on the frontend client browser.

## Phase 2: Core Inventory & Procurement System Engine

### 2.1 The "True Landed Cost" Mathematical Framework
The application ensures item processing accuracy by allocating all logistically required operational overhead into the catalog base evaluation profile. 

                      [ Raw Invoice Cost (Qty × Base Rate) ]
                                        +
                         [ Total Transport Surcharges ]
                                        +
                          [ Unloading Labor Expenses ]
                                        │
                                        ▼
[ Total Item Base Units Received ] ───► Divide Sum Total ───► [ Calculated Actual True Landed Cost ]


When tracking inbound items across delivery workflows, operations evaluation metrics resolve through the following structural formula logic:

$$Landed\ Cost\ Per\ Unit = \frac{(Quantity \times Unit\ Rate) + Transport\ Cost + Labor\ Cost}{Quantity}$$

### 2.2 Atomic Batch Write Execution Chain
